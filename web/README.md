# web/

Dashboard (React 19, Vite 8, Tailwind 4, Recharts). **Owner:** Dev 3.

Pages: Overview, Agents, Agent detail (premium history), Jobs, Job detail
(checks, every AI vote with its TEE attestation status, settlement breakdown),
Simulation (findings from `sim/`), Try it (runs a demo job through the judge).

## Run

```bash
npm run web              # from the repo root, http://localhost:5173
```

Mock mode is on by default. Copy `.env.example` to `.env.local` and set
`VITE_USE_MOCK=false` to read the live contract on testnet instead.

## Data

- Contract and receipt shapes are imported from `@surety/shared/types`
  (docs/SPEC.md sections 4.5 and 6), so the dashboard cannot drift from the contract.
- Live mode: read-only RPC view calls (`list_agents`, `list_jobs`, `get_job`, ...).
  No wallet.
- Receipts: `GET {VITE_DEMO_API_URL}/receipts/:job_id/verdict.json` (SPEC section 7).
- Mock mode: `src/mock/fixture.json`, generated by `npm run mock:data -w @surety/web`,
  which runs a small scenario on MockChain. Every amount follows the contract rules.
- Simulation: `public/sim/summary.json` and `rounds.json`, written by `npm run sim`.
